Department-wise Performance

Every student carries a DepartmentID, so department is the one dimension that cleanly slices CGPA, pass rate and attendance. Use the slicer to drill into one department at a time.

DAX — measure 
Avg CGPA by Dept = AVERAGEX( VALUES(Students[DepartmentID]), [Average CGPA] )
Pass Rate %       = DIVIDE( CALCULATE(COUNTROWS(StudentPerformance), StudentPerformance[Result]="Pass"), COUNTROWS(StudentPerformance) )

02 · Distribution

Grade & Result Analysis

TotalMarks = Exam1 + Exam2 + FinalExam feeds a 7-band grade (F · D · C · B · B+ · A · A+) and a Pass/Fail result at the 30-mark line. This page shows how marks, CGPA and absences move together.

DAX — calculated column 
Grade Band = SWITCH( TRUE(),
    StudentPerformance[TotalMarks] >= 68, "A+",
    StudentPerformance[TotalMarks] >= 60, "A",
    StudentPerformance[TotalMarks] >= 53, "B+",
    StudentPerformance[TotalMarks] >= 45, "B",
    StudentPerformance[TotalMarks] >= 38, "C",
    StudentPerformance[TotalMarks] >= 30, "D",
    "F" )

03 · Ranking

Top Performers & At-Risk Students

Two lists computed off the same table: the top 10 by CGPA for recognition, and every failing student for intervention — sorted by absences so the highest-attendance-risk cases surface first.

DAX — measure 
Top N Rank   = RANKX( ALL(StudentPerformance), StudentPerformance[Cgpa], , DESC )
At-Risk Flag = IF( StudentPerformance[Result] = "Fail" || StudentPerformance[Absences] > 15, "At Risk", "On Track" )

04 · Reference

Course & Faculty Directory

25 courses across 5 departments, taught by 15 faculty. This directory is descriptive reference data — see the callout below on why it can't be joined to individual exam performance.

Data model noteCourses aren't linked to marks. StudentPerformance has one row per student (overall CGPA/marks), not one row per student-per-course. Its raw CourseID column turned out to be a duplicate of Absences (identical values in every row), so it isn't a usable foreign key. A real Power BI model would need a proper Enrollments fact table (StudentID, CourseID, marks) to report performance by course — see the Data Model page for the fix.

Data quality findings from profiling

Fixed / CleanZero nulls and zero duplicate rows across all 6 sheets. TotalMarks and grade bands recompute exactly from source columns.
Broken keyStudentPerformance.CourseID is numeric (0–75) while Courses.CourseID is text (C001–C025) — and every value is an exact duplicate of Absences. It cannot be used to join performance to a specific course.
Mis-tagged rows3 Mechanical-sounding courses (Engineering Mechanics, Thermodynamics, Manufacturing Processes) are tagged D003 (ECE) instead of D004, and Surveying is tagged D004 instead of D005 (Civil). Recommend confirming with the source before reassigning.
Unrelated sheetThe student-mat sheet is the public UCI "Student Performance" dataset (Portuguese schools) — it has no StudentID or shared key, so it can't join to the GradeWise tables. Left out of this dashboard; useful only as a separate, standalone analysis.

Suggested calculated columns & measures for the Power BI build

Calculated columns 
Full Name        = Students[FirstName] & " " & Students[LastName]
Age at Admission = DATEDIFF(Students[DOB], DATE(Students[AdmissionYear],7,1), YEAR)
Grade Band       = SWITCH(TRUE(), ...)   -- see Grades page
At-Risk Flag     = IF(StudentPerformance[Result]="Fail" || StudentPerformance[Absences]>15, "At Risk", "On Track")
Key measures 
Average CGPA   = AVERAGE(StudentPerformance[Cgpa])
Pass Rate %    = DIVIDE(CALCULATE(COUNTROWS(StudentPerformance), StudentPerformance[Result]="Pass"), COUNTROWS(StudentPerformance))
Avg Absences   = AVERAGE(StudentPerformance[Absences])
At-Risk Count  = CALCULATE(COUNTROWS(StudentPerformance), [At-Risk Flag]="At Risk")
Top Student    = CALCULATE(MAX(StudentPerformance[Cgpa]))
